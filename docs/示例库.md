# 在线动画示例库

画廊是静态网站，访客不需要安装 Remotion。支持分类、标签、搜索、动画播放和效果链接，例如 index.html#cute-creeper-rush。

## 生成

在工程根目录完成 npm ci 和 npm run setup 后：

```bash
npm run fx -- previews all
```

生成 gallery/index.html、manifest.json、assets/ 和 previews/。这是包含视频的多文件站点，部署整个 gallery/。

已有预览，只更新页面时：

```bash
npm run fx -- html
```

只生成某个效果：npm run fx -- previews cute cute-creeper-rush。分类对应 src/entry-*.tsx。

## 发布

在线地址：https://rinorsi.github.io/Oriel-Video/ ，由 `gh-pages` 分支发布，源码分支 `main` 不含预览视频。

站点用的是精简预览：每个 MP4 取前 12 秒，crf 30，约 114 MB。重新发布：

```bash
# 1. 准备站点目录 <site>：manifest.json + previews/（jpg 原样复制，mp4 精简）
ffmpeg -i gallery/previews/<id>.mp4 -t 12 -an -c:v libx264 -crf 30 -preset medium -pix_fmt yuv420p -movflags +faststart <site>/previews/<id>.mp4
# 2. 生成页面
node scripts/build-site.mjs <site>
# 3. 把 <site> 的内容提交到 gh-pages 分支并推送
```

发布前确认 217 个条目都有 MP4 和封面，每个效果可通过 `#效果id` 单独分享。预览成片中涉及的游戏素材仍受 Minecraft 使用条款约束，字体许可随 assets/fonts/ 一起保留。
