# 在线动画示例库

画廊是静态网站，访客不需要安装 Remotion。支持分类、标签、搜索、动画播放和效果链接，例如 index.html#cute-creeper-rush。

## 生成

在工程根目录完成 npm ci 和 npm run setup 后：

```bash
npm run fx -- previews all
```

生成 gallery/index.html、manifest.json、assets/ 和 previews/。这是包含视频的多文件站点，部署整个 gallery/。

已有预览，只更新页面时：

```bash
npm run fx -- html
```

只生成某个效果：npm run fx -- previews cute cute-creeper-rush。分类对应 src/entry-*.tsx。

## 发布

可把 gallery/ 作为 GitHub Pages 的发布产物，或上传到静态站点服务。预览视频较大，推荐作为网站产物发布，避免放进源码分支。

公开后在 README 顶部放真实的「在线预览」链接，在 Skill 中也加入同一链接。用户点链接就能观看全部动画，每个效果可通过 #效果id 单独分享。发布前确认 217 个条目都有 MP4 和封面，并检查手机播放、搜索、分类和透明层标记。

目前还没有发布在线示例网址。预览成片中涉及的游戏素材仍受 Minecraft 使用条款约束，字体许可随 assets/fonts/ 一起保留。
