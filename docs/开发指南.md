# 修改与扩展

## 修改已有动画

1. 在 src/lib/catalog.json 按 id 或中文名找到条目，查看 export、props、frames 和 example。
2. 沿 src/lib/index.ts 的导出找到组件。物品动画公开接口在 src/lib/classicOthers/item.tsx，底层实现位于 src/gallery/fx/item/：craft、furnace、smithing、enchant、brew、drop、pickup、upgrade、rarity、chest、sort。
3. 换文字、物品、颜色或时间时先使用现有 props；没有所需参数，再修改实现并把参数传到库接口。
4. 展示、库接口、catalog 和 examples 一起同步。库接口内部会引用 src/gallery/fx/，移动代码时保留依赖。

不是所有参数都已开放。catalog 的限制与 TypeScript 类型共同决定支持范围。

## 做一支新视频

复制 src/lib/examples/episode.tsx 到 src/my-video.tsx，将从 '..' 的导入改为 './lib'，再将 ScenePlate 占位镜头替换成自己的录屏。录屏放 public/footage/。

新建 src/my-video-entry.tsx：

```tsx
import {Composition, registerRoot} from 'remotion';
import {EpisodeExample, EPISODE_FRAMES} from './my-video';
import {withFonts, FPS, WIDTH, HEIGHT} from './lib';
const Episode = withFonts(EpisodeExample);
registerRoot(() => <Composition id="MyVideo" component={Episode}
  durationInFrames={EPISODE_FRAMES} fps={FPS} width={WIDTH} height={HEIGHT} />);
```

```bash
npx remotion studio src/my-video-entry.tsx
npx remotion render src/my-video-entry.tsx MyVideo out/my-video.mp4
```

命令在工程根目录执行。效果约定尺寸为 1920×1080、30fps。视频总长度用 seriesFrames 计算。

## 新增效果

在 src/gallery/fx/<分类>/ 登记展示效果；需要独立分类时增加 src/entry-<分类>.tsx 并接入 src/gallery/all.ts。提供可复用接口时，同步 src/lib/ 的实现或包装、catalog/<分组>.json 和 examples/，从 src/lib/index.ts 导出。

```bash
npm run catalog
npm run typecheck
npm run fx -- previews <分类> <效果id>
npm run fx -- export <效果id>
```

catalog 会同步 src/lib/catalog.json 和 docs/catalog.json。参数变化后也要核对 docs/库目录.md。渲染后检查开头、动作峰值、切镜点和结尾；改透明层时验证透明通道与实际叠加效果。

## Skill 下载包

需要 Python 3。在仓库中运行：

```bash
npm run skill:build
```

输出 out/skill/youyiku-video/ 和可下载的 out/skill/youyiku-video.zip。解压 ZIP 后得到同名 Skill 文件夹，安装时保留完整目录。assets/youyiku-kit.zip 包含当前工作文件，包括尚未提交但未被忽略的源码；发布前检查 git diff 和新增文件。assets/youyiku-kit.json 记录来源提交、文件数和 SHA256。生成物、游戏资源、录屏和音乐不打入包。

源文件在 skill/youyiku-video/，不带工程压缩包，不能替代下载包。改完重新构建，不为打包自动提交或推送。

安装后的 bootstrap.py 使用完整路径调用，目标目录必须为空；--no-install 和 --no-setup 可分别跳过依赖安装与游戏资源提取。已有工程直接使用，不覆盖解压。

## 宣传片

时间轴是 src/promo/Promo2.tsx，素材准备脚本是 promo/prep.py。需要 Python 3、numpy、ffmpeg、已生成的 gallery/ 和自行提供的 public/promo2/audio/bgm.mp3。运行 npm run promo:prep → npm run promo。用 npm run dev:project 预览 Promo2。
