# 视觉方法总结

> 我们做视频时实际用过的视觉/技术方法，以及踩过的坑。以后新效果直接从这里挑方法，不重新摸索。代码位置均在 `src/` 下。

## 1. 像素纪律（让画面「像游戏」）

- **GUI 缩放 4**：Ore 风格所有尺寸取 `U=4` 的倍数（`src/mg/Ore.tsx`），斜面、字、间距在同一网格上。
- **字体按整数倍**：Fusion Pixel 12px 取 12/24/48/96/144；8px 取 8/32。中文粗标题用 Noto Sans SC Black 在粗网格上栅格化（`mg/BlockText.tsx`）。
- **最近邻放大**：所有像素贴图 `imageRendering: pixelated`。
- **低分辨率画布再放大**（`mg/LowRes.tsx`，480×270 ×4）：光线、光晕、粒子、传送门漩涡等在小画布上画，放大后自然是大像素，不是矢量。
- **位置吸附到格**：爆发/碎片用 `snap`，抖动也吸附到格子。

## 2. Ore UI 的做法

- 用 CSS `border-image` 九宫格切 `public/oriel/ore/*.png`（panel/slot/button/tooltip/tab/toggle/track/fill），与模组 `kit/ore.css` 同源（`nine()`）。
- 按钮三段式（顶亮边/主体/底暗边），按下时整体下沉 2 个 GUI 像素。
- 物品栏槽 + 稀有度提示框（tooltip/tooltip_rare），文字逐字打出（`OreTooltip.reveal`）。

## 3. 动效与节奏

- **确定性**：不用 `Math.random`，用 `mulberry32(seed)`；一切由 `useCurrentFrame()` 推出，任意帧可复现。
- **曲线**：`EASE.out / inOut / in / back`（过冲）；蓄力→爆发→回弹；挤压拉伸（squash & stretch）；果冻抖动；停顿帧(hitstop)；震屏吸附到格子。
- **转场架构**：`TransitionDef` 有 `a(p)`/`b(p)` 样式、`overlay` 覆盖层、`strips` 横条错位、`cues` 音效；两类——**cut**（覆盖层在 p=0.5 盖满、B 接管）与 **dual**（A/B 各自变换）。`transitionEntry()` 自动生成演示和透明层。
- **时间轴**：cut 型转场让下一镜头提前 6 帧开始；镜头内入场动画留出前半段给转场。
- **视觉表达优先于文字**：动作靠鼓胀/闪白/碎屑/烟团/挤压表现，不用拟声字。

## 4. 冲击与特效的「现代像素」画法

- **取代扩散圆环**：`Shockwave` = 像素十字闪光(前 1/3 寿命) + 阶梯三格拖尾碎片射线 + 带重力的碎屑方块，全部吸附到格；位置在 `src/mc/Fx.tsx`。
- 粒子只用方块/十字/细长矩形；闪电用阶梯折线；火星上飘；烟用原版 `big_smoke_*` 序列帧；爆炸用 `explosion_*`。
- 白闪峰值 ≤0.5，避免盖住透明层叠加的素材。

## 5. 质感

- **三件套**：深色描边一圈 + 浅色高光边 + 向下偏移的硬投影（不用大模糊阴影）；可爱风用 `flat.tsx` 的 `flatBox`/`Sticker`。
- **硬阴影标题字**（地下城风）：近黑色向右下偏 2–3px，不是描边。
- **纸张卷曲**（`fx/trans2/bookFlip.tsx`）：把页面切成 ≥24~40 条竖条，沿卷起曲线逐条做透视旋转，叠曲面明暗、边缘高光、下页动态投影、纸背透字。
- **真实 3D 木箱**（`fx/trans2/box3d.tsx`）：CSS 3D，各面用原版 `entity/chest/normal.png` 的 UV 裁切。
- **缓存**：画布类效果把静态层预渲染到离屏 canvas，逐帧只合成。

## 6. 真实素材的使用

- `npm run setup` 从游戏 jar 提取贴图（含全部 `entity/*`）与音效。
- `src/gallery/mob.tsx`：`Crop` 按 UV 裁切；`CreeperHead`、`EndermanHead`(含发光眼)、`VillagerHead`(含长鼻)、`PigHead`、`ChestFront`。UV 速查表在文件顶部注释。
- 皮肤脸：`PlayerFace`（`mg/Ore.tsx`）。

## 7. 地图与程序化场景

- **像素羊皮纸地图**（`fx/map/mapgen.ts`、`journey.tsx`）：噪声地形(海岸/森林/山/河/沙)、村庄图标、罗盘/比例尺/图例/小地图/黑白格边框；虚线路径逐段绘制，头像沿路径弹跳，镜头 拉远→推近→拉出，到站旗帜+标牌+像素爆发。
- 路线类型：步行/多站/矿车(铁轨)/骑马/珍珠抛物线/鞘翅/乘船/回家/重生/极简现代地图。

## 8. 地下城风格的光影（2D 模拟 3D）

（引擎在 `src/gallery/fx/mcdscene/`）
- 斜俯视等距方块渲染，面明暗 顶1.0 : 左0.78 : 右0.60，顶面边缘细亮边；阴影 = 受光色×0.6~0.7，主光左上。
- 双层泛光（~1% 与 ~4–6% 帧宽）、体积雾、金色斜射 god rays、暗角、按群系调色。
- 品红光柱(#CD2ECD 白核)用于开箱；稀有度光柱 白/绿/橙；灵魂=小鬼脸+青蓝拖尾。
- 世界地图 = 米色羊皮纸上的等距悬浮岛沙盘，金色六边形节点。

## 9. 评审方法（保证质量的关键）

- `fx sheet`：3×2 时间联系表（10%…93%），一眼看节奏与满不满。
- `fx frame`：单帧细看；`--alpha` 看透明层。
- **与真实参考图并排比对**，逐项列差异再修。
- 检查最后/最大帧的文字是否居中、出框、重叠；检查四象限与四角是否有内容。
- 子代理自检两轮以上 + 主会话抽查 + 用户验收。

## 10. 踩过的坑（别再犯）

| 坑 | 教训 |
|---|---|
| 把「我的世界：地下城」想成通用暗黑 RPG，做成战力/伤害飘字/羊皮纸金边 | 学风格先**搜真实截图并看**；不是做玩法。该风格明亮、饱和、光影是重点，UI 是暗底+六边形/菱形 |
| 扩散圆环 | 没包装的环形很丑，所有效果禁用；换像素十字+碎片 |
| 手绘 MC 生物（村民/箱子/末影人） | 一律用原版贴图 |
| 拟声字（嘶/砰/哐当） | 有音效就不要文字，靠动画表现 |
| 文字没居中/出框/重叠 | 满宽 flex 容器居中；量墨迹包围盒；看最后一帧 |
| 画面空、轻浮 | ≥4 层、四角有内容、描边+高光+硬投影 |
| 放射线/星星/爱心堆砌「AI 味」 | 每个元素要有设计理由 |
| 稀有度用蓝色 | 地下城是 白/绿/橙 |
| python 静默失败 | 用 node |
| 子代理跨会话不能 SendMessage 续用 | 新开代理并把改动清单写全 |

## 11. 地下城风格新增方法（2026-11-06）

- **斜俯视体素光影引擎**（`src/gallery/fx/mcdscene/`）：seed 确定的体素世界 + 真实方块贴图最近邻放大；面明暗 顶1.0/左0.78/右0.60；阴影=受光色×0.6~0.7、左上主光；双层泛光(约1%与4–6%帧宽)、体积雾、金色 god rays、群系调色；烘焙一次逐帧合成。`<ScenePlate biome=... />` 直接当转场/加载/标题背景。
- **UI 几何语言**（`fx/mcdkit/`）：六边形(等级/难度/节点)、菱形(附魔/结算金框)、45°斜切角面板，无圆角；三层硬斜面槽；顶亮边/主体/底暗边三段式按钮；粗像素标题字+向右下偏移的**硬阴影**，墨水框精确居中（`PxText`）。
- **真实 3D 部件模型**：生物用 8×8×8 等部件按真实 UV 拼成立方体、真实比例（头/身/手/腿），微侧 3/4 视角；红描边沿 3D 投影的真实轮廓描（`fx/mcd5/mobCard.tsx`）。
- **光柱语言**：开箱=品红 #CD2ECD 白核 4 帧冲出；稀有度光柱 白/绿/橙；路标=竖直光柱+菱形标记+距离。
- **克制的转场**：地下城以压黑硬切/白闪/光柱/横幅为主；我们的转场也以此为骨架，再加体积光扫过、薄雾、方块升起、灵魂扫过等。
- **叠加层的混合模式**：调色=正片叠底，光雾/光柱/粒子=滤色；每个层在 Demo 角落标注推荐混合模式与不透明度；移轴模糊需包裹素材（叠加层拿不到底下画面）。
- **流程教训**：先搜真实截图并看（用 Bash curl 取图+Read 看；官方 wiki 被拦时用商店页/镜像/B 站实况截帧）→ 写 STYLE 指南 → 基础件(UI 套件+场景引擎) → 并行做效果 → 与真图并排比对。
